# 厂商三虚拟机生命周期

## 目标和接口范围

厂商三的 IP/MAC 由厂商网络分配，MP 不为它维护独立 IP 地址池。MP 分配 VMID，并从已接入的厂商 API 读取模板、集群资源和虚拟机配置，优先完成同一虚拟机的创建。HTTP 受理响应不等同于完成，业务 success 字段、实际状态及配置回读均参与判断。不假设已有接口之外的异步任务查询接口。

## 创建流程

1. 获取完整资源清单并确认模板和计算节点；暂时不可查询时继续核对。
2. 在独立事务中持久化 VMID、场景节点关联和唯一的 MP_CREATE_ 请求名称。编号取厂商当前 VMID（包括模板和非 MP 资源）、MP 历史关联和台账中已分配编号的最大值之后的编号。数据库唯一键保证多实例并发不会分到同一 VMID；明确的编号冲突且已确认对应请求名称不存在时，最多重新分配 10 次。旧编号保留，不反复利用。
3. 提交克隆，记录受理状态和返回的任务标识（如有）；查询同一 VMID/名称的资源，等待克隆解锁、状态明确。超时或响应丢失不触发第二次克隆。
4. 对停止且已解锁的虚拟机按最新 digest 配置目标网络，并回读。配置未确认时继续检查，最多提交 3 次，并给异步配置留出收敛时间。已经匹配的网络不重复配置。
5. 开机并轮询实际运行状态；明确被拒绝时最多尝试 3 次，已受理或不确定的请求继续核对，而不是盲目重发。读取实际 vnet0 中的 IP、MAC 和网络标识，验证运行状态及地址后才返回 READY。网关及掩码仅在厂商配置提供时回写，不用镜像地址替代。
6. 超过等待窗口仍未确认时，保留台账和 VMID，节点显示待核查/异常。同一节点再次进入创建流程时优先继续原 VM，避免再次克隆。

厂商侧 running + 配置中的实际地址是本流程的就绪口径，并不代表 Guest 操作系统已完成启动或其业务服务已可用。

## 电源与回收

三家厂商统一从 MP 的开机、关机、重启处理入口分发。重启使用确认关机后再开机。厂商三根据当前资源清单选择实际计算节点，结合原场景节点、VMID 和唯一创建名称校验资源归属。

回收先确认同一 VM 的状态，关机后再删除；明确拒绝时有限重试，结果不确定则继续读取资源清单。仅在完整清单中确认 VMID 及原资源名称均不存在，并具有曾观察到该资源或者从未提交克隆的证据后，才结案。回收失败保留原始关联，不因 HTTP 200 就标记删除成功。

此前未建立台账的历史节点：已确认不存在的 VMID 可以幂等回收；如果仍存在但没有可核查的原始创建名称，不自动停止或删除，需要先核实原始归属。避免误操作由历史重复 VMID 指向的其他虚拟机。

2026-11-28 修正：既无 VMID 又无任何资源台账的历史节点，在成功读取完整清单后完成本地节点回收并记录告警，不再因空 VMID 阻塞整个拓扑；该分支不发送厂商删除请求，也不表示找到了未知的历史 VM。有未结案台账的创建继续按原请求核对。前台实例已明确关闭、MP 场景 DELETE/ABNORMAL 的历史场景，由新增重试任务调用正常场景删除流程收尾，详见 `vendor_reclaim_recovery_20261128.md`。

## 定时核对

每分钟读取待确认、回收中和失去活动的创建记录：
- 确认迟到的 running 和正确网络 IP/MAC 后，更新台账并补回原活跃场景节点的资源标识、IP/MAC。
- 回收中已确认消失的资源结案。
- 异常中断的创建保留关联；明确未提交的过期预占可结案。
- 定时任务不代替场景生命周期再次发起克隆、开机或删除，不自动将整个场景事件改为成功。尚未完成的创建需由原创建入口继续。

## 默认配置

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| XD_THREE_NETWORK_ID | 原厂商三配置中的网络 UUID | 由现场网络配置决定 |
| XD_THREE_CLONE_TIMEOUT_MS | 600000 | 克隆状态等待窗口 |
| XD_THREE_NETWORK_TIMEOUT_MS | 120000 | 配网和回读等待窗口 |
| XD_THREE_READY_TIMEOUT_MS | 600000 | 开机及 IP/MAC 等待窗口 |
| XD_THREE_DELETE_TIMEOUT_MS | 300000 | 关机、删除及消失确认窗口 |
| XD_THREE_POLL_MS | 3000 | 状态轮询间隔 |

这些是各阶段轮询窗口，不是整个创建的固定耗时。厂商单次请求有自身网络超时；实际完成后立即进入下一阶段。

上线需随 MP 发布数据库迁移 `V202611261000__vendor_third_vm_ledger.sql`（MySQL/DM）。现场需使用真实厂商接口确认一次完整创建、IP/MAC 回读、开关机和删除，以及并发场景成功率。当前离线测试不代替现场验收。
